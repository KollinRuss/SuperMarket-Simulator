# Supermarket Simulator

A C++ application that simulates the basic operations of a supermarket.

## Features

- Display supermarket information
- Display aisles and items
- Customer checkout
- Manage inventory quantities
- Calculate total sales
- Display total funds
- Pay employees
- Manage supermarket members

## Technologies

- C++
- CMake
- Object-Oriented Programming
- File I/O

## How to Run

1. Clone or download this repository.
2. Open the project in CLion or another C++ IDE that supports CMake.
3. Build the project.
4. Run the program.
5. When prompted, enter the path to `supermarket_data.txt`.

## Project Structure

- `main.cpp` - Starts the program and displays the main menu.
- `supermarket_simulator_program_3.cpp` - Contains the main supermarket functionality.
- `supermarket_simulator_program_3.h` - Contains the project declarations and structures.
- `supermarket_data.txt` - Contains the supermarket data used by the program.
- `CMakeLists.txt` - Configures the project build.
